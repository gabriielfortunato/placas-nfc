# Gerenciador de Placas NFC & QR Code Dinâmico

Sistema web simples para gerenciamento de placas NFC e geração de QR Codes dinâmicos com atualização de destino em tempo real.

## Recursos
- Cadastro de IDs de placas únicas.
- Configuração de links de destino instantânea.
- Geração de QR Code automático para gravação em Tags NFC ou impressão.
